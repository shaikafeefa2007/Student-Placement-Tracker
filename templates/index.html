🎯 About Student Placement & Skill Tracker

Student Placement & Skill Tracker is a web-based platform designed to help students organize and monitor their placement preparation.

The application brings technical skills, DSA, aptitude, reasoning, student profile, certifications, projects and placement applications together in one centralized platform.

Technology Stack: Python • Flask • SQLite • HTML • CSS • JavaScript
